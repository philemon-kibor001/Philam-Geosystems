# # 🗺️ Philam Geosystems
### Technical Geospatial & Survey Management Platform

> A full-featured web application for private geodetic engineering and survey firms in the Philippines.
> Built with **Streamlit**, **Folium**, and **Pandas** — deployable in one click to Streamlit Cloud.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io)
![Python](https://img.shields.io/badge/Python-3.10+-blue)
![License](https://img.shields.io/badge/License-MIT-green)

Philam Geosystems streamlines land survey operations — from GPS/GNSS data collection
and parcel registration to interactive GIS map visualization and DENR-compliant
report generation. Designed for PRC-accredited geodetic engineers and survey firms
operating under NAMRIA and LRA standards.
